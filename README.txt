책상 위 AR 캐릭터 - 사용법
==========================

[폴더 구성]
  index.html   : AR 페이지 (이 파일 하나가 전부예요)
  models/      : 나중에 블렌더 모델을 넣는 폴더 (지금은 비어 있어요)
  README.txt   : 이 설명서


1. PC에서 미리보기
------------------
- index.html을 크롬으로 열면 임시 캐릭터가 보여요.
- 마우스로 드래그하면 돌려 볼 수 있고, 휠로 확대/축소돼요.
- 인터넷이 연결되어 있어야 해요. (three.js를 인터넷 주소에서 불러와요)
- PC에서는 카메라 AR이 안 되고 3D 미리보기만 돼요.


2. 폰에서 AR 확인 (호스팅 후)
-----------------------------
- 이 폴더를 GitHub Pages 같은 https 주소에 올린 뒤 폰으로 링크를 열어요.
- 안드로이드(크롬): [AR로 보기] → 카메라 허용 → 책상 비추기
                    → 하얀 원이 보이면 탭 → 캐릭터가 올라가요.
                    다른 곳을 탭하면 캐릭터가 그 자리로 이동해요.
- 아이폰(사파리): [AR로 보기] → 아이폰 AR 화면이 열리고 책상 위에 캐릭터가 놓여요.
                  임시 캐릭터는 아이폰에서는 움직이지 않아요.
- 아이폰 크롬: 사파리와 같은 방식으로 열려요. 안 열리면 사파리로 열어 주세요.
- 카카오톡 등 앱 안의 브라우저에서는 AR이 안 될 수 있어요.


3. 블렌더 모델로 바꾸기
-----------------------
models 폴더에 아래 이름으로 파일을 넣으면 임시 캐릭터 대신 자동으로 나와요.
코드는 고칠 필요 없어요.

  models/character.glb   (필수) 안드로이드·PC용
    - 블렌더: File > Export > glTF 2.0 → 형식 "glTF Binary (.glb)"
    - Animation 옵션을 켜 두세요. 첫 번째 애니메이션이 반복 재생돼요.
    - 크기는 신경 쓰지 않아도 돼요. AR에서 자동으로 키 10cm로 맞춰요.
    - 발이 바닥(원점 높이)에 닿게, 앞모습이 -Y 방향(블렌더 정면)을 보게 만들어 주세요.

  models/character.usdz  (선택) 아이폰용
    - 블렌더: File > Export > Universal Scene Description → 파일 이름을 .usdz로
    - Animation 옵션을 켜면 아이폰에서도 움직여요.
    - 이 파일은 크기 자동 조절이 안 돼요. 블렌더에서 실제 크기(약 0.1m)로 맞춰 주세요.
    - 이 파일이 없으면 GLB 모델로 아이폰용 파일을 자동으로 만들어요.
      (이 경우 아이폰에서는 움직이지 않아요)

※ models 폴더의 파일은 호스팅한 뒤에만 불러와져요.
   PC에서 index.html을 그냥 열면 보안 때문에 임시 캐릭터가 나와요.


4. 크기 바꾸기
--------------
index.html 안의 AR_HEIGHT_M = 0.10 숫자를 바꾸면 돼요. (0.15 = 15cm)
